# 实施顺序

| 阶段 | 工作 | 完成标准 |
| --- | --- | --- |
| 1. 所有权骨架 | 新增知识库与 MCP 表、迁移、Valibot 契约、账户删除清理 | 两个用户不能读取、修改或删除对方资源；删除账户无残留密钥 |
| 2. 知识库 MVP | 文本与 Markdown 写入、分块、数据库任务、全文检索 | 文档更新可重建索引；失败任务可重试；检索始终限制用户与知识库 |
| 3. MCP MVP | 远程 HTTP 连接、工具发现、允许列表、工具调用、审计 | SSRF 用例被拒绝；密钥不出现在响应和日志；调用可取消和超时 |
| 4. 对话接入 | 为现有 `McpToolRuntime` 增加托管实现；聊天检索托管知识库 | Web 与 Electron 登录后可使用同一托管知识库和远程 MCP |
| 5. 向量检索 | 增加 embedding Adapter、向量列、重建任务和混合排序 | 模型版本固定；重建可恢复；无 embedding 时全文检索仍可用 |
| 6. 运行加固 | 限流、配额、指标、租约恢复、审计保留与负载测试 | 多 API 实例不重复处理任务；外部故障不会阻止健康检查 |

# 首版明确不做

- 不提供组织、团队、角色和共享知识库。
- 不在服务器执行用户提供的 MCP `stdio` 命令。
- 不支持 PDF、Office、网页抓取和 OCR。
- 不新增独立向量数据库、对象存储或消息队列。
- 不把完整 MCP 参数、结果或文档正文写入普通日志。

# 必须保留的测试

- 每个资源 API 都有双用户隔离回归测试。
- 知识库任务覆盖重复执行、旧版本任务、租约过期和删除竞态。
- MCP Adapter 覆盖私网地址、重定向、DNS 重绑定、超时、取消和超大响应。
- 账户删除覆盖文档、片段、任务、MCP 密钥和审计记录。
- 多实例测试证明一个任务只提交一次最终索引结果。
